# Build / CI-CD setup (Tank)
- **Makefile** targets (run via `bobp make`): help, lint (node --check), test (node --test test/*.test.js), check (lint+test), status, push (check then clasp push), deploy (push then clasp deploy), pull.
- **.claspignore**: only *.js and appsscript.json (test/, docs/, agents/ etc. never uploaded). NOTE: test/*.js excluded by `!*.js` only matching root; src/** allowed for future.
- **.github/workflows/ci.yml**: PR/push -> `make check`; push to main -> `make push`. Needs repo secret CLASPRC_JSON (contents of ~/.clasprc.json after `clasp login`). Uses plain `make` since bobp is not in CI.
- **test/smoke.test.js**: placeholder so harness is exercised; Neo adds real tests (format.test.js ...). Test files must be named test/*.test.js and use a guarded `module.exports` in source.
- Not verified: clasp push/deploy (needs auth + touches live script; run deliberately). Project is not a git repo, so the workflow takes effect once pushed to GitHub.
